
# 🎮 Console-Based Tetris Game (C++)

## 📌 About the Project
This is a simple console-based Tetris game developed using C++. The game allows players to control falling blocks, arrange them to complete horizontal lines, and score points.

This project was created to practice and improve C++ programming skills.

## ✨ Features
- Console-based gameplay
- Different Tetris block shapes
- Player-controlled block movements
- Score tracking
- Line-clearing functionality
- Game over detection

## 🛠️ Technologies Used
- C++
- Dev-C++ / C++ Compiler

## ▶️ How to Run
1. Download or clone this repository.
2. Open the project file in a C++ IDE.
3. Compile and run the program.
4. Enjoy playing Tetris!

## 🎯 Learning Outcomes
- Improved C++ programming skills
- Practiced loops and conditional statements
- Understanding of game logic
- Problem-solving and logical thinking
